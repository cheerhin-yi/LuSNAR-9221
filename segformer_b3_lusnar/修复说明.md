# SegFormer-B3 连接超时修复

你提供的日志显示，图像/标签检查已全部通过，失败发生于：

```text
SegformerConfig.from_pretrained('nvidia/mit-b3')
Connection to huggingface.co timed out
```

原因是旧脚本默认下载 ImageNet 预训练模型，而当前网络无法连接该站点，本地又没有缓存。

本修复版默认从随机初始化离线训练，直接执行 train 不再下载外部模型。
启动时明确打印 `Initialization: RANDOM / OFFLINE`，并记录到 initialization.json；没有自动伪装为已加载预训练。
需要预训练时，仍可明确使用 `--pretrained` 指向本地完整模型目录，并加 `--local-files-only`。
本修改避免训练依赖在线下载，不改变当前电脑的网络连通性。

## 替换和重跑

将压缩包中的 segformer_b3_lusnar 文件夹解压合并到 D:\LuSNAR_Seg，覆盖同名脚本和说明。
包内不包含 runs 目录，现有训练结果可以保留。

在原来已激活 lusnar 的命令行运行：

```bat
cd /d D:\LuSNAR_Seg\segformer_b3_lusnar
python train_segformer_b3.py train --output runs\segformer_b3_offline
```

或者在已激活环境的命令行运行：

```bat
run_train_offline.bat
```

旧日志显示还没开始第一轮，不要加 --resume。
新运行完成一轮后中断，才可使用：

```bat
python train_segformer_b3.py train --output runs\segformer_b3_offline --resume
```

默认仍为 FP32、100 轮、batch=4、512 裁剪、原来的数据目录和场景划分。
如果 runs\segformer_b3_offline 已经有 last.pth，请恢复它，或给新实验换一个输出目录。
训练效果需根据实际验证/测试指标和预测图检查；随机初始化的收敛条件与 ImageNet 预训练不同。

验证：完整 B3 在 CPU 合成数据上完成一轮训练、验证、测试、预测图、best/last 保存；测试强制禁止调用 pretrained 加载接口，确认默认运行不依赖网络。
开发端无法直接访问目标机器数据或 GPU，因此尚未对目标 CUDA 环境实测。
